# 技术、规范、设备与计算审核

按实际工程选择相关检查项；本参考不内置工程合格限值，也不替代适用标准原文。

## 1. 证据优先与规范适用

建立规范核验表：引用原文｜准确名称/编号/年份｜发布/实施/废止状态｜项目适用日期和过渡规定｜对象及阶段｜方法条款｜判定条款｜核验来源/日期｜核验状态。

- 核对 GB 与 GB/T、JTS 与 JTS/T 等编号属性，不能凭前缀直接认定某条强制性；强制性条文以正式发布依据为准。
- 分清“试验方法”“产品允许偏差”“施工过程控制”“实体质量验收”“检测评估”各自适用范围。施工预警值不自动成为交工合格值；工艺评定不自动等于现场验收。
- 地方实施细则只有在地域、工程类别、检测阶段及用户指定依据吻合时采用。征求意见稿不作为已生效文件。
- 新版发布不自动证明旧版用于该工程错误；核验实施日期、过渡安排、合同设计约定及强制要求。旧版仍有效也不证明对象适用。
- 设计图、变更、合同、委托要求的层级及一致性需要明确；不得以模板意见替代经确认的项目设计判据。
- 官方状态页只证明状态或元数据，不证明未见到的具体条款。付费、访问受限或本地缺页时记录待核实，不猜条号。

## 2. 范围与抽样

核对工程总量、抽样总体、构件类别、部位、批次、测点/测区/构件数与抽样比例。分母应与判定单元一致，不能用测点合格率代替构件合格率，或将不同类别混合后掩盖单类不合格。

检查抽样规则是否覆盖整个总体；编号范围、分层抽样、既有/新建构件与检测对象应可追溯。不能把邻近构件尺寸当成本构件尺寸，也不能把周长、直径、中心高程、前沿高程混为一谈。缺图纸时提出对象核对，而非强行改数。

按单位工程/合同段/结构类别保持评定边界；有未检、未评价或排除项时，汇总结论不能扩大为“全部项目合格”。标准养护试块、施工自检资料、设计批复与实体检测、竣工设计评价不是等价证据。

## 3. 设备与检测方法

逐项目核对：参数｜方法｜设备名称/型号/唯一编号｜量程/分辨力/精度｜测量模式｜附件及传感器｜检定/校准/核查｜检测日期和批次。

- 核实证书对应仪器、序列号、量程、日期、覆盖参数及适用周期。校准证书未写“有效期”不自动无效，应查机构管理周期和实际复核记录。
- 报告列一个检校日期不能证明全部历史批次有效；证书未附也不能直接判超期。
- 测量精度应与允许偏差/变化量相匹配。GNSS静态、RTK、全站仪和水准测量各按实际模式、网形、闭合差、平差与观测条件评定，不能只凭品牌/型号否定。
- 设备表缺回弹仪、保护层仪、超声仪、厚度仪或测深设备时，先核具体项目；船名、软件名不能替代传感器型号及校准证据。
- 核验材料、龄期、表面状态、温度、含水、耦合、修正、测线/扫描等级、测区数等方法适用条件。设备能读数不等于方法适用。

## 4. 可复算的数据链

对关键计算保留可运行代码或计算记录：原始值及位置、公式、单位换算、上下限及是否包含边界、数据剔除/修正依据、舍入阶段、计算结果、报告结果、差异及结论影响。

- 原始测值→测点/测区代表值→构件结果→合格数量→合格率→加权评分→综合结论，逐层检查。
- 比率明确分子分母；百分数先计算再按规定舍入。无规定时披露采用的舍入约定，不将银行家舍入/四舍五入混用造成的末位差异夸大为实质错误。
- 超限判定区分原始单值、平均值、最小值和分位统计；不能擅自给平均值套单点限值或相反。
- 时间跨度由完整日期计算；总变化/间隔是区间平均速率，不是最大日速率。水平分量与平面合量分别计算，沉降正负号和基准点变化需说明。
- 加权分值先查权重、缺项处理、满分分母和扣分依据。报告明确给定口径时，内部算术不一致可标已确认，但不代表规范适用已确认；口径不明、需要额外假设时，仅可给出明确假设下的条件性复算。
- 对龄期、取样/检测/检校/完工/报告日期检查先后关系；旧结构可能合理存在高龄期，不直接改成新建日期。
- 相同序列、固定偏移和异常整齐先标原始记录追溯，不能仅据数列模式推定造假。

同一错误传播到汇总、结论或附件时，各位置单独批注并关联首个计算问题。不得只在一个表里指出而放过错误总评。

## 5. 整改与结论

“已整改”需与缺陷编号、部位、处理方案、日期、复查方法/数据、照片及确认人建立对应。注意检测时与整改后是不同时间截面；保留历史缺陷不等于目前未整改，但缺少复核证据不能无条件闭合。

建议由发现推导，区分资料补充、复算、复测、设计核验、结构专业复核。缺证据时不设计加固方案、不出具安全可用保证。
