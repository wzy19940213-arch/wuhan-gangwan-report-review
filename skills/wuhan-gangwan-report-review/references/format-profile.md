# 约定格式基准（不是国家标准）

本表是本工具的默认工作格式。当前用户明确要求、业主模板、合同及适用法规优先；存在更具体模板时先读取正文和批注。仅因不符本表，不得称其违反中国规范或质量不合格。PDF只在能可靠识别时判断字体/字号，否则记录视觉问题或待核源文件。

| 项目 | 默认约定 |
| --- | --- |
| 页面 | A4纵向；上/下2.54 cm，左/右3.18 cm；宽表或专业图纸可按批准模板横向 |
| 正文 | 中文宋体小四，数字/英文Times New Roman小四；1.5倍行距，首行缩进2汉字 |
| 标题 | 一级宋体小三加粗，二级四号加粗，三级小四加粗；更深层用(1)、①、(a) |
| 目录 | 默认到二级；更新标题、页码及链接，不以旧目录代表实际页码 |
| 表格 | 参考宽15 cm、五号字、外框1.5磅；实际不得超出版心（A4及上述页边距净宽14.64 cm），按版心调整；行高随内容增长，不截字、不机械锁死 |
| 图表标题 | 宋体小四加粗；默认右对齐；按二级章节编号，如表5.1-1；项目模板可覆盖 |
| 照片 | 默认7×5 cm，说明放下方；保持比例和辨识度，不能为凑尺寸裁掉关键证据 |
| 公式 | 可编辑公式，主体居中、编号右对齐，符号和单位定义完整 |
| 页眉页脚 | 项目名称、报告编号、页码/总页数一致；正文与附件编号体系明确 |

检测报告通常含工程概况、检测依据、人员设备、内容方法、数据分析、结论评估、建议和附件。该章节链只作内容完整性检查，不机械重排用户已有章节。

封面、注意事项、资质、签字表、目录检查：项目及委托名称、报告编号、检测类别、日期、编写/审核/批准角色与正文一致；签名、盖章和资质要求来自实际制度或适用依据，未核时不作强制性断言，不代签盖章。

逐页查看孤行、截字、跨页表头、空白页、图片挤压、公式缺字、字体替换、引用、页码和附件缺失。每处格式问题独立批注；不在首处用“全文同改”替代其余位置。OCR错字应先与原图对照，不将提取错误误报为原文错误。
